# TaskPilot CLI

A menu-driven Command Line Interface (CLI) Task Management Application built using Python. The project helps users manage daily tasks efficiently with features such as task creation, editing, deletion, searching, filtering, sorting, and persistent file storage.

## Features

* Add new tasks with priority and due date
* View all saved tasks
* Mark tasks as completed
* Delete tasks
* Search tasks by keyword
* Filter tasks by priority, status, or due date
* Edit existing tasks
* Sort tasks by priority, due date, or creation date
* Persistent storage using text files
* Input validation and exception handling

## Technologies Used

* Python 
* File Handling
* Functions
* Dictionaries
* Lists
* Exception Handling
* Modular Programming
